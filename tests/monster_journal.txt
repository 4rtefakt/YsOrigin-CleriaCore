# The game's own MONSTER JOURNAL, entries 1..68 (the non-boss set), as published.
# Columns: No  Name  HP  LV  STR  DEF  EXP
#
# This is the only EXTERNAL check we have on the enemy stat pipeline. Everything else
# validates our C++ against our Python -- both reading the same bytes, both able to
# share one wrong idea. These numbers come from the game's own in-game journal, so
# reproducing them exercises the GAMEINFO curve, the ENEMYINFO log2 multipliers, the
# level column and the fold(cast_id-14) index, all at once, against a source that
# knows nothing about our parse.
#
# It immediately earned its keep: it proved the engine FLOORS rather than rounds.
# With floor, 67/68 match exactly on HP/LV/STR/DEF. With round, 9/68.
#
# KNOWN BAD ROW: #50 Kelmarel lists DEF 200. Our data says 191, and matches on HP
# (433), LV (36) and STR (193). Rows 48/49/50 all show DEF 200 and EXP 357 -- a value
# copied down a column in the published table. We do NOT correct our data to match it.
#
# The journal's order is ENCOUNTER order, not ENEMYINFO index order, so entries are
# matched by value rather than position.
#
# Boss entries (69..92) are deliberately absent: the journal fills their columns from
# DIFFERENT difficulties (HP from Easy, STR from Normal, DEF from Hard, EXP from Very
# Easy, SP from Nightmare), so no single run of our formula should reproduce a boss row.
